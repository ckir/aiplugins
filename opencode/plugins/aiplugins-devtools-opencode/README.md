# aiplugins-devtools-opencode

An OpenCode plugin that ships dev-tool skills. The first skill is
`code-review-and-quality`, a multi-axis code review (correctness, readability,
architecture, security, performance) with security and performance checklists.
It carries only skills: no plugin code, no hooks, no MCP servers, no binaries.

## Installation

See [INSTALL.md](INSTALL.md). It is a file copy of the skill folder into
OpenCode's `skills/` directory; there is no `opencode.jsonc` to merge.

## Invocation

OpenCode keys a skill by its folder name, so here the skill is invoked as
`aiplugins-devtools-code-review-and-quality`. A colon is not valid in a folder
name, so the `aiplugins-devtools:` form used on the other agents is not
available on OpenCode.

### Context footprint

Installing this plugin adds **≥ 388 bytes** to every request, for the whole session. A further **≥ 20,674 bytes** load only when one of its skills or agents is actually invoked.

| Tier | Bytes | When you pay it |
|---|---|---|
| Resident | ≥ 388 | Every request, for the whole session |
| Invocation | ≥ 20,674 | Only when that skill or agent runs |

**Bytes, not tokens.** This is the exact serialised size of what the host loads, measured by probing the plugin's own MCP server and reading its skill and agent frontmatter. It is not a token count and does not convert to one at a fixed rate — treat it as a figure you can compare between plugins, not as a context budget.

**≥, because hook output is excluded.** Measuring it would mean executing the plugin's hooks against a synthetic event, which this tool will not do. A plugin whose hooks emit a large preamble costs more than the figure shown.
