# opencode-ctl-mcp-qwen — OpenCode worker sessions for Qwen Code

This extension lets Qwen Code delegate bounded work to an [OpenCode](https://opencode.ai) worker session over
MCP: start and inspect the OpenCode service, create sessions, send prompts, wait for the turn, read the messages
and the changes, and answer permission and form requests.

## Architecture

All behaviour lives in the shared `opencode-ctl` engine (`shared/opencode-ctl`), the same code the Claude Code
and Antigravity fronts use. This extension contributes only the Qwen-shaped glue:

- **`qwen-extension.json`** — MCP server registration (`opencode-ctl-qwen-mcp serve`)
- **`src/main.rs`** — the thin binary: names the host (`Host::Qwen`), the product and the version
- **`skills/`** — `opencode-ctl-driver` and `opencode-ctl-doctor`, generated by `emit-skill --host qwen`

Use the `opencode-ctl-driver` skill for the delegate-and-verify workflow and `opencode-ctl-doctor` when a tool
fails with `OPENCODE_NOT_FOUND`, `SERVICE_DOWN`, `AUTH_FAILED`, `UNKNOWN_OPERATION` or `REFUSED_ON_HOST`.

`session_wait` blocks for one slice of `wait_timeout_s` (120 s by default); the extension raises the MCP call
timeout to 330000 ms so a slice is not cut off by the host.
