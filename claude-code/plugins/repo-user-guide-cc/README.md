# repo-user-guide

A Claude Code plugin that ships the `repo-user-guide` skill: it produces a PDF
user guide for a code repository, with usage examples that are run and verified
before they go into the guide.

Install:

```
claude plugin install repo-user-guide@aiplugins
```
