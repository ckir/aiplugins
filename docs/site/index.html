Why AI Plugins?

Purpose-built tooling designed to make autonomous AI coding assistants safer, faster, and dramatically cheaper.

Zero-Compile Instant Installs

Prebuilt, tested native binaries for Windows (x64), Linux (x86_64, aarch64), and macOS (x86_64, Apple Silicon). Single-line install commands configure tools and hooks immediately without compiler toolchains.

Context Footprint Transparency

Every plugin measures exact Resident vs Invocation vs Setup bytes before install. Enforced context budget gates ensure your LLM prompt windows remain clean, token-efficient, and fast.

Cross-Agent Unified Rust Core

Shared memory-safe Rust crates in shared/ power native adapters across Claude Code, Google Antigravity, OpenCode, and Qwen, eliminating divergent plugin behaviors.

Understanding Context Footprints

Every byte of schema loaded by an agent consumes precious LLM context window memory.

Resident
What the host holds in every request, for the whole session: MCP tool schemas plus frontmatter loaded to decide what each skill and agent is for.
Invocation
Loads only when a tool or skill is actively executed by the agent during a workflow step.
Setup (OpenCode only)
An OpenCode plugin also loads its setup module in-process with the host on every request, as a third tier on top of the two above.

These are bytes, not tokens: the exact serialised size of what the host loads. Compare them between plugins; they are not a context budget.

Quick Install

Connect your preferred autonomous agent environment to the AI Plugins marketplace.

Claude Code

Register the entire marketplace catalog with one command:

claude plugin marketplace add ckir/aiplugins

Google Antigravity

Install curated skills and custom tools directly into ~/.gemini/antigravity-cli:

curl -fsSL https://raw.githubusercontent.com/ckir/aiplugins/main/install-agy.sh | bash

OpenCode

Add the marketplace config to your OpenCode configuration:

opencode plugin add ckir/aiplugins

Qwen

Download and extract prebuilt extensions into ~/.qwen/extensions:

curl -fsSL https://raw.githubusercontent.com/ckir/aiplugins/main/install-qwen.sh | bash
